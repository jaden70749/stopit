# 하차벨 중간평가 시연 가이드

## 실행

- 공개 주소: https://hachabell-stopit.vercel.app/?demo=1
- 일반 모드: https://hachabell-stopit.vercel.app/
- 로컬: Node.js 22에서 `npm run dev` 실행 후 `http://localhost:4173/?demo=1`.
- 녹화 전 사이트 소리를 허용하고 화면을 한 번 클릭합니다. 모의 이동은 약 40초입니다.
- 모의 좌표와 가상 버스 99를 사용하는 시연입니다. 실제 버스 탑승이나 실시간 운행을 검증한 영상으로 설명하지 않습니다.

## 약 3분 기능 시연

1. 시연 주소를 열어 SIMULATION 표시, 모의 출발지와 목적지, 가상 버스 99를 보여줍니다.
2. 경로 카드의 승차·하차 정류장과 지도 선을 설명합니다. 이 경로 자체는 발표용 가상 자료입니다.
3. 기본 400m 기준에서 `경계 밖 420m`를 누릅니다. 거리 계산 결과는 420m, 알림은 발생하지 않아야 합니다.
4. `경계 안 380m`를 누릅니다. 계산 결과는 380m, 큰 하차 안내가 나타나고 지원하는 환경에서는 알림음·진동이 발생합니다.
5. `처음으로`를 누르고 `이동 재생`을 누릅니다. 지도 점과 거리가 바뀌고 400m 이내에서 알림이 발생합니다. 한 번 알린 뒤 계속 이동해도 중복 알림이 없어야 합니다.
6. `일시정지`, 재생, 초기화를 보여줍니다. `알림 거리·소리 설정`에서 기준을 200m로 바꾸고 경계 밖 220m/안 180m도 비교할 수 있습니다.
7. 상단 `실제 GPS로 돌아가기`로 시연을 종료합니다. 일반 모드에서 장소 검색과 실제 카카오 경로 조회가 별도 기능임을 설명합니다.

## 실행 순서와 코드

```text
일반 모드: GPS 좌표 수신
시연 모드: demoPosition(progress)에서 모의 좌표 생성
공통: currentPosition과 destination으로 distanceBetween 계산
tracking && !alerted && remainingDistance <= alertRange 일 때 notifyReached
notifyReached: alerted = true, 화면 안내, 지원 시 소리·진동
초기화: 타이머 중지, 위치 복원, 추적·알림 상태 초기화
```

실제 경로: 브라우저가 출발·도착 좌표를 `/api/transit`에 전달하고 서버가 REST 키로 카카오를 호출합니다. 서버 응답의 노선·정류장·경로 좌표가 UI와 지도에 표시됩니다. 시연 모드는 외부 API 없이 demo.js의 표시된 가상 경로를 사용합니다.

## 자동 검증

`npm run check:demo`는 CDN에서 HTM을 읽으므로 인터넷이 필요합니다. 실제 App을 모의 타이머·GPS·소리 객체와 함께 실행합니다.

| 조건 | 기대 결과 | 구현 후 자동 검사 |
| --- | --- | --- |
| 시연 주소 진입 | 실제 GPS 요청 0회 | 통과 |
| 기준 400m, 모의 거리 420m | 알림 없음 | 통과 |
| 모의 거리 380m | 알림 표시 및 진동 요청 1회 | 통과 |
| 알림 후 계속 이동 | 중복 알림 없음 | 통과 |
| 일시정지 | 모의 타이머 제거 | 통과 |
| 처음으로 | 알림 해제, 출발 위치 복원 | 통과 |
| 도착 후 재생 | 조기 알림 없이 출발부터 재시작 | 통과 |
| 실제 모드 복귀 | 모의 타이머 제거, GPS 요청 재개 | 통과 |

이 검사는 브라우저와 하드웨어를 대체한 상태 흐름 검사입니다. 실제 지도 렌더링, 스피커 재생, 휴대전화 진동, 실외 GPS와 백그라운드 실행을 통과했다고 의미하지 않습니다.
