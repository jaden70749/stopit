# 하차벨 시연

시연 주소: https://hachabell-stopit.vercel.app/?demo=1

화면은 기존 앱과 같습니다. 시연 주소에서만 GPS 입력이 선택 경로 좌표 재생으로 바뀝니다.

1. 목적지를 검색하고 선택합니다.
2. 대중교통 경로를 조회한 뒤 원하는 버스 경로를 선택합니다.
3. 이 목적지 하차 알림 설정 → 하차 알림 시작을 누릅니다.
4. 현재 위치 점이 선택 경로를 따라 약 45초 동안 이동합니다.
5. 마지막 하차 정류장에 설정 거리 이내로 접근하면 기존 화면 안내와 알림음이 발생합니다.
6. 알림 끄기로 중지하고 다시 시작하면 같은 경로를 처음부터 재생합니다.

일반 주소에서는 기존 실제 GPS를 사용합니다. 상단의 작은 ‘시연 · 모의 GPS’ 표시로 구별합니다. 고정 가상 노선, 별도 시연 패널, 경계 이동 버튼은 사용하지 않습니다.

현재 위치 권한과 실제 경로 조회는 필요합니다. 모의 좌표 이동은 실외 GPS 검증과 구별해서 설명합니다. 알림음은 브라우저와 스피커 설정의 영향을 받으므로 녹화 전에 확인합니다.

검사: npm run check:demo

검사는 실제 API의 버스 경로를 사용해 기존 화면에서 목적지 검색·경로 선택·경로 좌표 이동·하차 정류장 도착·알림 1회·중지와 재시작을 확인합니다. 모의 타이머·소리 객체를 사용하는 코드 검사이며 실제 브라우저 지도나 하드웨어 소리를 검증한 것은 아닙니다.
